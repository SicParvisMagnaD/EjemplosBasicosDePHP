## ⚙️ Requisitos

Se necesita un entorno local que integre servidor web, base de datos y soporte para PHP. En mi caso trabajé con **WampServer**, que reúne Apache, MySQL y PHP en una sola instalación para Windows.

📌 **Nota:** WampServer no es un servidor por sí solo, sino un paquete que agrupa varias herramientas para simular uno en la computadora local.

**Editor de Código:**
- Visual Studio Code

## 🛠️ Cómo usar este repositorio

1. Clona el repositorio y colócalo dentro de la carpeta `www` de WampServer (o `htdocs` si usas XAMPP):

git clone https://github.com/SicParvisMagnaD/EjemplosBasicosDePHP.git


2. Con el servidor activo, accede desde el navegador a:
 http://127.0.0.1/practicas/ o http://localhost/practicas/
